# Salamander Grand Piano

Recorded piano samples by Alexander Holm, licensed under
[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).

These MP3 files were copied without modification from the
[Tone.js audio repository](https://github.com/Tonejs/audio/tree/master/salamander).
The note mapping follows the [Tone.js sampler example](https://tonejs.github.io/examples/sampler).

The original sample collection README is included as `README` in this directory.
